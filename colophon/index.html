    //How is this site made?

    This site is fully static.

    Hosting

    • GitHub Pages

      Free hosting for static websites.

    Framework

    • TanStack Start + TanStack Router

      React 19 framework with file-based routing. Used here with static prerendering so every page is shipped as plain HTML, with no runtime server required.

    • Tailwind CSS v4

      Utility-first styling. The palette is a small set of CSS variables defined twice, once for the dark theme and once for the light one, so both modes share every component.

    Design

    • Chakra Petch and Saira

      Two typefaces, both served by Google Fonts: Chakra Petch for the name, headings, navigation and anything that is data (dates, counts, labels), Saira for everything that gets read.

    • The order-book landscape

      The backdrop behind my name is a synthetic limit order book drawn as a landscape: each slice is a depth chart, bids on one side and asks on the other, receding in time, with the mid price running along the canyon floor. It is hand-written on a plain 2D canvas with its own perspective projection, with no 3D library, and it pauses when it scrolls out of view or when reduced motion is requested.

    • Lucide

      General-purpose interface icons. The few brand marks (GitHub, LinkedIn, X, YouTube) are inline SVG.

    Content

    • Typed data, no CMS

      Every page is built from plain TypeScript files, one set per language, so the English and French versions cannot drift apart structurally.

    • Blog and YouTube feeds

      The latest posts and videos are read from the RSS feeds of the blog and of both YouTube channels when the site is built, then shipped as part of the static page.

    Analytics

    • Umami (self-hosted)

      Privacy-friendly, GDPR-compliant analytics running on my own server. No cookies and no personal data leave the page.

    Development

    • Claude Code

      The current design, the order-book landscape and the content pipeline were built in pair-programming sessions with Anthropic's Claude Code.
